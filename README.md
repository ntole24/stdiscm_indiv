# stdiscm_indiv

Setup and Run
- Replace the numbers in config.txt with your specified values for n, t1, and t2.
    - NOTE: each of these values can be any positive long integer. However, since t1 and t2 represent minimum and maximum times for an instance to finish, the value of t1 cannot exceed the value of t2.

- Compile and run main.java with this command:
    
    javac main.java && java main [t] [h] [d]

    - NOTE: [t], [h], and [d] can be any positive long integer value.
